# 标签页保险箱 · Tab Dashcam

给浏览器装一台行车记录仪：**持续记录所有窗口和标签页的状态**，误关窗口、浏览器崩溃、重启之后，能把「当时那一刻」整窗还原回来。

Chrome / Edge 扩展 · Manifest V3 · 无联网、无上传、无统计

**English**: a browser dashcam for your tabs — snapshots every window and tab locally, then restores a whole window (order, pinned, tab groups) after an accidental close or a crash. *Restore closed tabs · tab session manager · window backup · crash recovery.*

![界面预览](docs/screenshot.png)

## 为什么需要它

Chrome 自带的历史记录救不了你。它是**按访问时间排列的流水账**，还会把同一个网址合并成一条——它能告诉你「三周前看过这篇文章」，但还原不出「2 号窗口那 23 个标签」这个集合。

而「最近关闭」只保留 **25 条**，关掉一个 20 标签的窗口只占 1 条记录，随便再关几次就被冲掉了。这就是「手滑关掉一个窗口，几十个页面再也找不回来」的真正原因。

这个扩展不去修补历史记录，而是另建一条**本地状态时间线**：每分钟检查一次所有窗口和标签，有变化才记一条快照。误关之后，从这条时间线里把整窗原样重建。

## 安装（3 分钟，不需要懂代码）

### 方式一：下载安装包（推荐）

1. 点进 [`dist/tab-dashcam-v1.1.1.zip`](dist/tab-dashcam-v1.1.1.zip)，在页面右上角点 **Download** 图标下载
2. 双击解压，得到一个文件夹（名字类似 `tab-dashcam-v1.1.1`）
3. 打开 **Chrome 浏览器**，地址栏输入 `chrome://extensions` 回车
4. 打开页面**右上角的「开发者模式」开关**
5. 点左上角出现的 **「加载已解压的扩展程序」**，选择刚解压出来的那个文件夹（选文件夹本身）
6. 点工具栏右上角的**拼图图标**，找到「标签页保险箱」，点旁边的**图钉**固定
7. 点工具栏图标 → 选 **「打开时间线 →」**，侧边栏出现就装好了

### 方式二：下载整个仓库

点页面右上角绿色 **Code → Download ZIP**，解压后得到 `tab-dashcam-main` 文件夹，然后从上面的第 3 步开始做（选 `tab-dashcam-main` 文件夹）。

装好之后**不需要做任何操作**，正常用浏览器就行。

> 首次安装时 Chrome 会提示「开发者模式扩展」，这是本地加载扩展的正常提示，点「保留」即可。

### 方式三：在 Microsoft Edge 里安装

Edge 是 Chromium 内核，**装的是同一个文件夹，不用改任何东西**，侧边栏也是原生支持的：

1. 打开 **Edge 浏览器**，地址栏输入 `edge://extensions` 回车
2. 打开页面**左下角（部分版本在右侧）的「开发人员模式」开关**
3. 点 **「加载解压缩的扩展」**，选择解压出来的那个文件夹
4. 点地址栏右侧的**拼图图标**，把「标签页保险箱」固定到工具栏
5. 点图标 → **「打开时间线 →」**，Edge 右侧侧边栏就会出现

> Edge 版本需要 **114 或更高**（侧边栏 API 从这个版本开始支持）。查看版本：`edge://settings/help`.
> Edge 上架不需要注册费（Chrome 商店要 5 美元），所以将来如果你想让别人也能从商店一键装，Edge 是成本更低的那条路。

**同一个安装包还能装在这些浏览器里**：Brave、Vivaldi、Arc、Opera 等 Chromium 内核浏览器，步骤同理（打开 `brave://extensions` 之类的地址）。没有侧边栏 API 的浏览器（如 Opera），扩展会自动改用一个独立小窗来显示时间线，功能一样。

### 关于 Safari

**Safari 不能直接装这个扩展，需要重做一版。** 原因不是"没适配"，而是苹果的机制不同：

- Safari 扩展必须打包成 Mac App，用 Xcode 编译签名，再通过 App Store 分发（公开分发需要每年 99 美元的 Apple 开发者账号）
- Safari 缺少这个扩展依赖的三个关键 API：`sessions`（关闭瞬间抢救整窗标签）、`tabGroups`（标签分组）、`sidePanel`（侧边栏）

所以在 Safari 上只能做一个"七成功能版"：自动快照和逐条恢复能用，但误关窗口的实时救援、标签分组、侧边栏界面都没有。如果你确实需要，可以另开一版精简实现。

## 怎么用

| 场景 | 操作 |
| --- | --- |
| 手滑关了整个窗口 | 弹出通知「已保存刚才关闭的窗口」，点「立即恢复」，整窗回来（顺序、固定标签、标签组都在） |
| 通知没看到 / 已消失 | 点插件图标 → 打开时间线，红色那条就是，点「立即整窗恢复」 |
| 浏览器崩了 / 强制退出 | 重开浏览器后，侧边栏顶部提示「疑似上次未正常关闭」，点「恢复这个会话」 |
| 只想从旧快照捞一个页面 | 时间线里点开对应那条 → 在标签列表里点那一个，只开它，不打扰当前工作 |
| 想把某刻的现场留档 | 时间线右上角「＋」手动存一条 |

## 它是怎么工作的

- 后台每 **1 分钟**检查一次，**标签有变化才写入**一条快照（没变化不产生垃圾数据）
- 标签新建 / 关闭 / 移动、窗口开关时，立刻补记一次
- 窗口关闭的那一刻，从浏览器里把整窗标签**抢救出来**单独存一条，并弹出通知
- 存储有上限：最近 40 条全留，1 天内全留，7 天内按小时抽稀，更早按天留，超过 90 天自动清理（可在设置里改）

## 隐私

- **所有数据只存在这台电脑的浏览器里**（IndexedDB，库名 `tabvault`）。扩展不联网、不上传、不做统计
- 只读取标签页的**网址、标题、图标、顺序、固定状态、分组**，不读取网页内容、表单、密码
- 无痕窗口不记录（扩展在无痕模式下不运行）
- 设置页可一键「清空全部记录」，卸载扩展数据随之删除

完整说明见 [隐私政策](https://parall.github.io/tab-vault-privacy/)。

## 已知限制（诚实说明）

1. **浏览器扩展无法「拦截」关闭动作**——没有关闭前的钩子。所以是「关闭后 1 秒内恢复 + 通知你」，体感接近撤销，但不是阻止
2. `chrome://` 开头的内部页、扩展商店页等特殊页面，网址可能拿不到或无法重开，会漏掉这几个
3. 后台脚本会被浏览器休眠省电，靠定时器唤醒，极端崩溃场景下「最后一秒」的状态可能有几十秒缺口。日常误关不受影响（走实时事件）
4. 恢复时会跳过无法直接打开的 URL（如 `chrome://newtab`），其余标签顺序保持不变
5. 对着「当前这一刻」的记录点整窗恢复，会在浏览器里多出一个一模一样的窗口。v1.1 起恢复前会检查，发现相同窗口要先点第二次确认

## 文件结构

```
.
├── manifest.json          # 扩展配置（MV3）
├── background.js          # 后台：自动快照、误关捕获、崩溃守卫、通知
├── lib/
│   ├── util.js            # 设置、时间格式化、哈希等
│   ├── db.js              # IndexedDB 存储 + 分级清理
│   ├── model.js           # 快照数据模型
│   ├── restore.js         # 整窗恢复（顺序/固定/分组）
│   └── backup.js          # 导出导入
├── sidepanel/             # 主界面（时间线）
├── popup/                 # 工具栏弹窗
├── options/               # 设置页
├── icons/                 # 16/32/48/128 图标
├── docs/                  # 截图
├── dist/                  # 安装包（只保留当前版本）
└── LICENSE                # MIT 许可证
```

## 开发者备注

- Manifest V3，最低 Chrome 116（`sidePanel.open` 需要）
- 权限：`tabs`（读标签网址标题）、`sessions`（取回刚关闭窗口的标签）、`storage` + `unlimitedStorage`（本地存快照）、`alarms`（定时快照）、`notifications`（误关提醒）、`sidePanel`（主界面）
- **无 host permissions**，不向任何页面注入脚本，不使用远程代码
- 修改代码后重新打包：`GITHUB_TOKEN=xxx python3 tools/sync_to_github.py "改动说明"`。脚本会自动按 `manifest.json` 的版本号打包成 `dist/tab-dashcam-v{版本}.zip`、把 README 里的下载链接改成当前版本、并删掉 `dist/` 里的旧包

## 更新记录

版本号规则：三段数字 `主.次.修`（如 `1.0.0`、`1.0.11`、`1.0.20`），每次改动只递增最后一位，不做大跳。`dist/` 目录只保留当前版本的安装包，旧版本会随新版本发布被移除。

- **v1.1.1** — 设置页新增「窗口诊断」，可导出浏览器实际报告的窗口结构（id、状态、位置、每个标签），用于核对窗口数量；恢复前查重改为重合度判断（≥60% 即提醒），那个窗口里新开了标签也能拦住；「现在 N 个窗口」改为只统计含可恢复标签的窗口，与快照口径统一
- **v1.1.0** — 采集改为一次性读取窗口与标签（避免两次读取之间状态错位，导致「一个窗口被记成两个」）；同一快照里内容完全相同的窗口会被标注出来；整窗恢复前先检查浏览器里是否已开着相同窗口，避免多开副本；无侧边栏 API 的浏览器自动降级为独立小窗；补充 Edge 安装说明
- **v1.0.0** — 首个版本：自动快照、时间线、整窗恢复、误关通知、崩溃守卫、导入导出
