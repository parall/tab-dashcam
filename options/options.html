标签页保险箱

自动记录所有窗口与标签页，误关、崩溃后可一键整窗恢复

记录

数据

–条记录
–占用空间
–当前窗口
–当前标签

备份是一个 JSON 文件，包含全部快照和设置，可以存到网盘或另一台电脑上再导入。

窗口诊断

如果侧边栏显示的窗口数和你屏幕上看到的不一致，点下面的按钮，把浏览器实际报告的窗口信息导出来。里面只有窗口位置和标签地址，不含任何网页内容。


    


    

      
隐私

      
    
        
  • 全部数据只存在这台电脑的浏览器里，插件不联网、不上传、不统计。
    • 
        
  • 只读取标签页的网址、标题、图标、顺序、固定状态和分组，不读取网页内容、不读取输入框、不读取密码。
    • 
        
  • 无痕窗口不会被记录（插件在无痕模式下不运行）。
    • 
        
  • 随时可以「清空全部记录」，或直接卸载插件，数据随之删除。
    • 
      

    


    

      
怎么用

      
    
        
  1. 正常用浏览器。插件在后台自动记录，不用做任何操作。
    2. 
        
  2. 点浏览器右上角的插件图标 → 选「打开时间线」，或固定在侧边栏常驻。
    3. 
        
  3. 误关窗口时，点通知里的「立即恢复」；或打开时间线，点那条「已关闭」的记录 → 整窗恢复。
    4. 
      

      
小提示：Chrome 自带的历史记录是按访问时间排列的流水账，还原不了窗口。这个插件存的是「某一刻所有窗口的完整状态」，所以能整窗还原。
